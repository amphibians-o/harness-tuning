# 対義語と対案（禁止文 → 肯定文）

禁止の言い回しは、書き手の推論を「しない方法」に割り当てる。対義語（望ましい状態）を書くと、推論がそちらへ向く。
この文書は**作り方**・**上位概念の使い方**・**対案の7型**・**検査**を持つ。SKILL.md の「3 変換」から読む。

## 作り方（チャンク単位で推論する）

1. 1文に切る（1チャンク＝1文。複数の行為が入っていれば分ける）。**機械的な文分割はファイル名や略語の `.` で切れる**ので、切った結果を目で見て直す。
2. その文が何をしているかを推論する: 行為への制約か／出力物の様式か／実測・因果の記述か。
3. 行為への制約なら、**対義語＝望ましい状態**を書く。
4. **望む姿＋完了条件**の1文にする（何が残れば終わりかを書く）。
5. 検査する（下記）。対応をこの表に1行足す。

**キーワード一致で機能を決めない。** 語の一致は候補を拾うまでに留める。同じ「〜しない」でも、様式の制約・実測の記述・行為の制約で扱いが違う。

## 対義語の作り方

### 素直な対義語があるとき

| 禁止の語 | 対義語＝望ましい状態 | レシピ |
|---|---|---|
| 汚さない／散らかさない | 綺麗に使う（綺麗にお使いいただきありがとうございます） | R3 |
| 報告しない／装わない | 報告に実行IDを添える。引用できる行を添える | R2 |
| 勝手に止めない／上げない | 停止と起動は本人が管理パネルから操作する。こちらは状態を読むだけ | R1 |
| 声を張らない／叫ばない | 落ち着いた声で話す | R3 |
| 先にXせずYする | XしてからYする | R4 |

### 対義語が浮かばないとき（上位概念へ上げる）

**上位概念を立て、その概念の望ましい状態を書く。**

| 禁止の語 | 上位概念 | 望ましい状態 |
|---|---|---|
| 見落とさない | 網羅性 | **範囲を確認して漏れなく推論する** |
| 数え間違えない | 計算の正しさ | **計算ロジックを検証する** |
| 嘘をつかない | 根拠の連鎖 | **根拠を再帰的に活用する** |
| 忘れない | 参照の確実性 | **在処を1行で残し、必要時に読み出す** |
| 遅れない | 進行の可視性 | **着手と完了を同じ場所に記録する** |

### ブラックリスト／ホワイトリストを使う場合

**望ましい状態を記述できる場合に限り**使う。禁止語や危険語を並べるだけの列挙は、書き手の推論を望ましい方向へ向けない。

- 使える形: 許可するものを挙げ、その**使い方の望ましい状態**を併記する。
- 使えない形: 「〜は禁止」の一覧だけを置く（読む側は回避の方法を推論できない）。

### 対義語を作らない（書き換えない）もの

- **書き換えずに残す制約**: 公開・課金・資源停止・原本と正本の変更／安全・セキュリティ・個人情報・他人の財産や尊厳への攻撃。
  → 生成文に混ぜず、**ラベル付きの門**（機械の検査）へ隔離する。行為者を「本人」に固定しても同値にならないものは、そのまま残す。
- **実測・因果の記述**（〜すると逆効果／〜が落ちる）: 否定形が事実。触らない。

## 対案の7型（抜け漏れを減らす）

| 型 | 何を突くか | 例 |
|---|---|---|
| 案 | そのまま置き換える | 「〜しない」→「〜する」 |
| 対案 | 反対の方向から同じ意図を満たす | 「静かにする」→「聞こえる声で一度だけ言う」 |
| 逆 | 反対語・裏返し | 使う／使わない、先に／後に、含める／除く |
| 対偶 | 条件を反転しても同じ意味か | 「〜ならX」→「Xでないなら〜でない」 |
| 上位概念 | 一段上の概念から望ましい状態を作る | 見落とさない → 網羅性 → 範囲を確認して漏れなく推論する |
| 前提の誤り | その文が前提にしている事実自体を疑う | 「毎回同じ手順で作る」→ 手順が固定である前提を確認する |
| 回答不能 | 情報が足りず決められないと明示して本人へ返す | 対象・行為者・完了条件が資料から引けない |

**3型（現状維持・対義語・行為者）だけでは抜け漏れの要因になる。** 7型を並べ、対照（書き換えていない元の文）を同じバッチに入れる。

## 選び方（型を並べたらどれを採るか）

- **純粋な対義語（「対案」「逆」の方向）は、元の禁止が禁じていた行為を許す方向へ緩みやすい。** 判定では「元の禁止が禁じていた行為を許していないか」の軸が低く出る。**行為者を固定して完了条件を書く形**（R1＋R3）のほうが、同じ肯定文でも禁止の強さを保つ。⇢ 緩みを測ってから採る。
- **書き換えない判断も結果の1つ。** 元の文がどの対案よりも上位になるチャンクは珍しくない（特に列挙型の禁止: 「質問も候補づくりも報告も不要」）。全チャンクを書き換える前提で始めない。
- **肯定形は語数が増える。** 同じ内容なら書き換えでトークンは増える。**トークン削減が目的の改訂では、書き換えではなく重複の除去を選ぶ。** 書き換えた場合は、増えた分を数えて報告に書く。

## 検査（採用の前に1回）

- 語の有無で決まる二値だけ: ①元の禁止が禁じていた行為を許していないか ②行為者が一意か ③完了条件があるか ④望む姿が肯定文か ⑤意図を落としていないか。
- **程度（score）は使わない**（同じ版を2回掛けると反転する）。
- **対照を混ぜる**: 書き換えていない元の文が最下位に来なければ、その設問は判別していない。
- **行動の一致（旧文と新文を同じ設問で比べる）**: 「この指示文を読んだエージェントが、この状況で〈禁じていた行為〉をしそうか」を旧文・新文の両方に掛け、**新文が旧文より高いなら戻す**。同じ実行の中で比べる（実行をまたぐと反転する）。
- **望む姿への書き換えは3軸で採る**（旧文と新文を同じバッチに置く）: ①肯定文になっているか ②元の文が防いでいた行動を許していないか ③読者が次に何をするか決められるか。**①が上がり、②が維持され、③が落ちていないときだけ採用する。**
- **肯定形にすると「いつ使うか」の手がかりが消えることがある。** ③（行動が決まる）が落ちた項目は不採用にし、**書き出しにトリガー（どの場面で使うか）を戻して**から同じ設問で掛け直す。
- 割れた項目は争点として本人へ返す（周回しない）。

## 失敗の型

- **語だけ置換して意味が変わる**（対象や範囲が入れ替わる）。→ 元の意図を1行で書き出してから置換する。
- **知見を肯定形にする**と事実が反転する。
- **上限・対象の制限を消す**（「だけ」を消すと探索が広がる）。
- **金額・単価・スコアを根拠に残す**。読者に意味がない私的データになるので、**根拠ごと書き換える**。
